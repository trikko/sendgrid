    Class SendGrid

    Main class to send emails using SendGrid

    class SendGrid; 
    auto result = new SendGrid("API_KEY")
	.addPersonalization(new SendGridPersonalization("john@example.com", "John Doe"))
	.from("you@example.com", "Your Name")
	.subject("Hello World")
	.addContent("<html><body><h1>Hello World</h1></body></html>", "text/html")
	.send();

    Methods

    NameDescription
    addAttachment (content, filename, type) Add an attachment to the message. If type is empty, the MIME type is guessed from the file extension.
    addAttachment (filename, type) Read a file from disk and add it as attachment to the message. If type is empty, the MIME type is guessed from the file extension.
    addBCC (email, name) Add a BCC recipient to every personalization of the message. SendGrid accepts BCC recipients only inside personalizations: this is a shortcut. Addresses already present in a personalization are skipped.
    addCC (email, name) Add a CC recipient to every personalization of the message. SendGrid accepts CC recipients only inside personalizations: this is a shortcut. Addresses already present in a personalization are skipped.
    addContent (value, type) Add a content to the message. More than one content can be added. text/plain content is always sent first, then text/html, as required by SendGrid.
    addPersonalization (personalization) Add a personalization to the message. At least one recipient is required.
    from (email, name) Set the sender of the message. Required.
    region (region) Send through the servers of a region
    replyTo (email, name) Set the reply-to address of the message
    send () Send the message
    sendAt (time) Set the time at which the message should be sent
    subject (subject) Set the subject of the message
    templateId (templateId) Set the template id for the message
